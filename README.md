# 🚀 Crypto Wallet API with Redis & JWT Authentication

This API provides user authentication, balance management, and cryptocurrency price fetching using **Node.js, MongoDB, Redis, and JWT**.

---

## 📌 Features
- **User Registration & Login** (with JWT)
- **Deposit & Withdraw (Crypto Wallet)**
- **Get Balance API**
- **Fetch & Store Crypto Prices in Redis** (CoinGecko)
- **PM2 for process management**
- **Uses MongoDB as Database**
